# redmineapp

Кроссплатформенный клиент Redmine с отдельным нативным окном на Go и Fyne.

Оформление в духе Tailwind: нейтральная серо-графитовая палитра с приглушённым сине-серым акцентом, парящие плитки, мягкие тени, скругления, подсветка выбранной задачи и приподнимание карточек при наведении. Тумблер «День · Авто · Ночь» доступен в боковой панели и на экране входа. В режиме «Авто» тема следует системным настройкам, выбор сохраняется. Реализовано нативно, без CSS и веб-движка.

## Возможности первой версии

- Несколько подключений; вход по API-ключу или по логину и паролю через HTTP Basic Auth.
- Выбор проекта: поиск по всему загруженному списку, сортировка, страницы по 20/50/100 записей, полный заголовок выбранного проекта.
- «Мои», «Слежу», локальное избранное, проекты и поиск темы или номера задачи.
- Открытые / закрытые / все задачи, постраничная загрузка по 50 записей.
- Описание и история комментариев; номера комментариев соответствуют позициям журналов Redmine.
- Создание и редактирование задачи, статус, приоритет, готовность и срок; назначение на себя.
- Комментарии и запись времени с выбором деятельности.
- Компактный поиск статуса с учётом разрешённых сервером переходов; кнопка «Закрыть» для перевода в закрытый статус.
- Изменение готовности нажатием на шкалу с шагом 10%, с возвратом прежнего значения при ошибке сохранения.
- HTTP-запросы выполняются в фоне; интерфейс не блокируется.
- Демо-режим (`--demo`) без сети, изменения живут до закрытия приложения.
- API-ключи и пароли — macOS Keychain, Windows Credential Manager, Linux Secret Service. При недоступности хранилища секрет остаётся только в памяти. Файл настроек не содержит ключей и паролей. Пароли разделены по серверу и логину.

На сервере включите **Администрирование → Настройки → API → Включить REST API**. На экране подключения выберите «API-ключ» или «Логин и пароль». Ключ находится в «Моя учётная запись». Для входа логином и паролем используется [стандартный HTTP Basic Auth Redmine](https://www.redmine.org/projects/redmine/wiki/Rest_api#Authentication); при серверной двухфакторной авторизации или входе только через SSO может понадобиться API-ключ. Сервер должен быть доступен по указанному URL без перенаправлений. Поддерживается установка Redmine в подпапке, например `https://example.org/redmine`.

## Запуск

Нужен Go 1.25+ и C-компилятор. Интерфейс работает без браузера, Node.js и Electron.

```sh
go run .
# Без сервера, с данными в памяти:
go run . --demo
```

Для macOS установите Command Line Tools (`xcode-select --install`). Linux: `sudo apt-get install gcc libgl1-mesa-dev xorg-dev libwayland-dev libxkbcommon-dev libegl1-mesa-dev`. Windows: MinGW-w64 GCC в PATH; сборка из Git Bash или MSYS2.

```sh
make test
make build
make package
```

## Пакеты

`packaging/package.sh` собирает пакет для текущей ОС:

- macOS 12+ arm64 / amd64: `redmineapp.app`, ZIP и DMG. Локальная сборка подписана ad hoc, без Developer ID и нотариализации Apple.
- Windows amd64: portable `redmineapp.exe`, ZIP и установщик Inno Setup в CI.
- Linux amd64 / arm64: tar.gz с `/usr`, `.desktop` и иконкой; DEB при наличии `dpkg-deb`. Установка DEB: `sudo apt install ./redmineapp-linux-amd64.deb`.

GitHub Actions в `.github/workflows/build.yml` запускает тесты и собирает пакеты на пяти нативных runner-ах. Они доступны как artifacts каждого запуска. Состояние сборок доступно в разделе [Actions](https://github.com/rkislov/redmineapp/actions). Сборка Fyne использует CGO: одной смены GOOS недостаточно. Альтернатива — [fyne-cross](https://docs.fyne.io/started/cross-compiling/) с Docker и соответствующим toolchain.

## Хранение данных

`os.UserConfigDir()/redmine-go/settings.json`: адреса и имена серверов, активный профиль, способ входа и логин, локальное избранное, выбранная тема. Ключ в системном хранилище привязан к URL, пароль — к URL и логину. Снятая галочка сохранения не удаляет секрет, сохранённый ранее; его можно удалить в системном менеджере секретов. Избранное хранится отдельно для каждого сервера. HTTPS рекомендуется; при HTTP данные входа передаются без шифрования. Проверка TLS включена, переходы HTTP запрещены, чтобы не передавать ключ другому адресу.

## Границы версии

Это первая рабочая версия. Вложения, аватары, уведомления, вики, вехи, доски, связи задач и полноценный рендеринг Textile пока не реализованы. Описание и комментарии отображаются исходным текстом, чтобы не интерпретировать Textile как Markdown. Список «Слежу» использует стандартный серверный фильтр `watcher_id=me`. Дополнительные обязательные поля и правила workflow проверяет сервер: ошибки API показываются пользователю. Администратор может ограничить доступ к справочникам и операциям.

Без доступа к вашему Redmine тесты проверяют взаимодействие с HTTP-сервером-имитатором, а не права и плагины конкретной установки. Для финальной проверки подключения нужны URL сервера и API-ключ или логин и пароль, которые вводятся в окне приложения.
